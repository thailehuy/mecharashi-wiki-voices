# mecharashi-wiki-voices

Pilot voice lines for the [Mecharashi fan wiki](https://mecharashi-wiki.cc/), served from `https://voices.mecharashi-wiki.cc/` and played on each pilot's Voice Lines tab.

`<lang>/<pilot ID>/<Wwise event>.mp3`, `lang` = `en` (English), `ja` (Japanese) or `zh` (Chinese). The files are generated by `scripts/extract_voices.py` in the wiki repo from the game's sound banks; don't edit them by hand. Pushing `main` deploys them (GitHub Pages).

> Fan project — not affiliated with Tentree Games / BlackJack Studio, non-commercial. The recordings belong to their owners; rights holders who want them taken down can open an issue.
